# 蓝色动态圣诞树 · 设计文档

日期：2026-11-18
状态：待确认（3D 版）

## 意图

做一个可以发给亲友的圣诞树网页：打开链接即是满屏深蓝雪夜，一棵由光点构成的圣诞树立在场景中，用户可以用手指或鼠标绕着它转动查看，极光在背景流动，雪在落。手机和电脑都要好看、流畅。

成功标准：手机上 3 秒内看见完整画面，拖动旋转顺滑；截图一发出去别人会问"这是哪做的"。

## 目标

- 真 3D：透视相机、可环绕旋转、有纵深与雾
- 视觉方向：极光雪夜（深墨蓝 + 冰蓝发光树 + 青色极光 + 3D 景深雪）
- 动态：树缓慢自转、极光漂移、雪落、星芒呼吸、指针视差、点击爆发光点
- 手指拖动可 360° 环视，松手有惯性，静止几秒后缓慢自转
- 点击/轻点有雪花与光波反馈，拖动会搅动雪
- 树下排一行细字 `MERRY CHRISTMAS`，小号 `2026` 附于下方
- 部署到 GitHub Pages，公开链接手机/电脑通用

## 非目标

- 无背景音乐/音效
- 无滚动长页、无多语言、无后台、无统计
- 不做写实材质（无贴图、无 PBR 材质、无外部字体）
- 不做祝福语编辑界面（内容写死在文件里，方便日后自己改）

## 反面目标（做到这些算失败）

- 看起来像模板或 emoji 拼的圣诞树
- 手机上掉帧、发烫、白屏等待
- 转动时穿帮、树变成一张扁片
- 点击反馈像廉价烟花，乱炸、糊屏
- 文字喧宾夺主，或字体像默认浏览器样式

## 技术方案

| 方案 | 取舍 | 结论 |
|------|------|------|
| Three.js（本地打包，真 3D + 泛光） | 依赖约 170KB gzip，存在仓库内，不依赖 CDN；真透视、真环绕 | **采用** |
| 手写 Canvas 2D 透视投影 | 约 30KB 最轻，但只能"看起来 3D"，无法自由环视 | 否决（用户要求 3D） |
| WebGL 全手写 | 无依赖，但辉光与场景管理成本高，易出兼容问题 | 否决 |

## 实现要点

**文件结构**

```
blue-christmas-tree/
├── index.html          # 页面：HTML + CSS + 应用逻辑（内联，分区块注释）
├── vendor/three.min.js # 本地依赖（r159 UMD，MIT），双击可离线打开
├── README.md           # 一句话说明 + 在线链接
└── docs/               # 本文档
```

**场景**

- 相机：40° 透视，位于树前方偏上；`OrbitControls` 不引外部依赖，自己实现环绕：水平 360°，俯仰限制 -8°～+28°，带阻尼惯性；10 秒无操作后恢复缓慢自转（约 0.06 rad/s）
- 树主体：约 2200 个光点（手机 1200）沿圆锥螺旋分布，加径向与高度抖动形成体积；顶点色为冰白 `#DFF6FF` → 天蓝 `#7CDFFF` → 深蓝 `#1B5BFF`，少量青色 `#4FD1E8` 点睛；近大远小、远处受雾衰减
- 光点渲染：`THREE.Points` + 自定义着色器，圆形软边衰减，加法混合，禁用深度写入，避免排序问题
- 挂饰：约 30 颗较大发光球体，沿螺旋错落分布，缓慢上下浮动
- 树顶星：八面体 + 加法混合光晕贴片，4 长 4 短星芒，呼吸 + 点击闪亮
- 背景极光：远处大平面着色器，多层噪声带缓慢漂移，深蓝到青蓝，低亮度
- 雪：3D 点云分布在相机周围的三层深度，各自速度与大小，缓慢侧向风摆，出界回绕
- 地面：圆形平面 + 径向渐变暗光，树底一圈淡蓝光池；`FogExp2` 压暗远景，让树从夜色里浮出来
- 泛光：自写两遍高斯泛光（半分辨率渲染 → 阈值 → 横竖模糊 → 加法合成），不引后处理依赖

**排版**

- `MERRY CHRISTMAS` 使用系统无衬线细体 + 宽字距，DOM 叠在画布上，页面加载后淡入
- 小号 `2026` 低透明度置于下方
- 画布 `aria-label`，`prefers-reduced-motion` 时关闭自转/漂移

**交互与反馈**

- 环绕：桌面拖拽 / 手机单指拖动，自身实现轨道相机，水平 360°，俯仰 -8°～+28°，带阻尼；松手 10 秒后恢复缓慢自转；不响应滚轮缩放，避免误触
- 点击判定：按下到抬起位移 < 8px 且时长 < 350ms 才算点击，拖动不触发爆雪
- 点击反馈（画面任意位置）：
  - 触点炸开 48 片六芒雪花精灵，3D 空间内随机向外散射，各自自旋、受轻微重力与阻力，1.2～1.8 秒淡出；对象池复用，不新建几何
  - 同时扩散一圈 24 个冰蓝光点，与雪花同源出发、更快更短命
  - 树顶星同步闪亮一次，亮度在 200ms 内回落到原值
  - 150ms 内只允许一次爆发，避免连点糊屏
- 点击命中树身：以点击世界坐标为原点，一道亮度波纹沿树身向外扩散（着色器以距离和时间计算），挂饰在波经过时被"点亮"
- 拖动：雪沿拖动方向被带起并轻微旋卷，树与近景雪产生视差；拖动过程中不发爆雪
- 桌面指针：跟随一枚柔光光晕（约 80px，低透明度），靠近挂饰时光晕变亮、挂饰放大 10%
- 首访提示：静置 3 秒后底部淡入一行小字 `拖动旋转 · 点击飘雪`，再过 5 秒淡出，仅首次出现（localStorage）
- 标签页隐藏时暂停渲染；尺寸变化自适应；像素比上限 2
- 低性能设备自动降级光点数与泛光分辨率
- `prefers-reduced-motion`：关闭自转、极光漂移与雪，只保留静态构图与点击反馈
